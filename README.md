# AccountHub feedback / フィードバック

This public repository accepts bug reports and feature requests for AccountHub. The AccountHub application source code is kept in a separate private repository.

この公開リポジトリでは、AccountHubの不具合報告と機能要望を受け付けます。アプリ本体のソースコードは別の非公開リポジトリで管理しています。

## Before opening an issue / 投稿前に

- Search [existing issues](https://github.com/k-ucchy/accounthub-issues/issues) to avoid duplicates. / 既存のIssueを検索してください。
- Do not post passwords, API keys, access tokens, personal information, private conversations, or unredacted screenshots and logs. Issues and comments here are public. / パスワード、APIキー、個人情報、非公開の会話、未加工の画面やログは投稿しないでください。Issueとコメントは公開されます。
- For a security vulnerability, use [private vulnerability reporting](https://github.com/k-ucchy/accounthub-issues/security/advisories/new) instead of a public issue. / セキュリティ上の問題は公開Issueではなく、非公開の脆弱性報告を利用してください。

Choose **Bug report** or **Feature request** from [New issue](https://github.com/k-ucchy/accounthub-issues/issues/new/choose). Reports are welcome in Japanese or English.

[New issue](https://github.com/k-ucchy/accounthub-issues/issues/new/choose) から「不具合報告」または「機能要望」を選んでください。日本語・英語のどちらでも投稿できます。

Maintainers may move sensitive details to a private channel and summarize only the public outcome here. A public report does not expose the private source repository.
